# data/ (git-ignored)

Empty on purpose. Put the hackathon bundle here (`data/tactical/…`, `data/broadcast/…`, the layout in
`reference/more-than-a-hack-2027/DATA.md`), or point `MTAH_DATA_DIR` at it.

Nothing in this folder is committed, apart from this README. The match data is licensed for the competition only and
must not be redistributed. The submission repo has to be public. No PFF data goes here either.

The terms also forbid uploading the data, or any extract of it, to a hosted LLM. Do not paste rows, plots or per-frame
outputs from these files into a chat assistant.
